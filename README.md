# 🚀 Overview

This is a **Hospital Management System** developed in **C++**.

The system helps hospitals manage patients, emergency cases, death records and file storage using a simple menu-driven console application.

Designed for beginners while implementing real-world programming concepts.

---

✅ Add Patient

✅ Update Patient

✅ Delete Patient

✅ Show Patient List

✅ Emergency Case Management
